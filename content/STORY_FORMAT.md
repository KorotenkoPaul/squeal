# Формат файла истории (content/stories/en/<id>.json)

Одна история — один файл, у всех одинаковый вид:

| Поле | Что это |
|---|---|
| `id` | короткое имя (латиница, через дефис) |
| `title` | название |
| `author` | автор |
| `genre` | `horror` / `thriller` / `romance` |
| `fear` | уровень страха 1–5 (внутренний, в приложении не показывается; работает шкала в поиске) |
| `description` | описание для превью (страница истории). Не инструкция к игре — см. STORY_NOTES.md |
| `interactive` | `true` — история с выбором (необязательно) |
| `featured` | `true` — всегда в слайдере (необязательно) |
| `endSound` | необязательно: звук `"sfx/<файл>.mp3"`, который проигрывается один раз сразу после последнего сообщения истории — при любой концовке; при повторном открытии дочитанной истории не играет. Сборка проверяет, что файл есть |
| `parts` | части истории по порядку (одна или несколько) |

Каждая часть (`parts[i]`):

| Поле | Что это |
|---|---|
| `prologue` | предисловие — серый текст в начале чата (2–4 предложения, без спойлеров) |
| `left` | собеседник (слева, его имя в шапке чата) |
| `right` | читатель (справа) |
| `wallpaper` | предметы-пасхалки для фона чата (имена иконок из библиотеки) |
| `messages` | сообщения: `{"from": имя, "text": текст}`; голосовое — ещё `"voice": "voice/<файл>.mp3"` и `"dur"` (секунды), а `text` — что сказано (показывается мелко под волной); видеокружок — `"video": "video/<файл>.mp4"` и `"dur"` (≤10 с), `text` — короткое описание для экранного диктора (на экране не показывается, без спойлеров). У интерактивной — самый длинный путь (для времени чтения и прогресса) |
| `start`, `nodes` | только у интерактивной: узлы переписки; у узла `messages` и либо `choices` (`text` — ответ читателя, `next` — следующий узел), либо `ending` (название концовки) |

Старые рукописи (Word/таблицы) из `legacy/` переводятся в этот вид скриптом `content/convert.py` (он даёт сырые файлы по частям; их потом собирают в одну историю и дописывают prologue, fear, wallpaper).

## Версия истории

При сборке приложения для каждой истории считается версия — короткий отпечаток её текста (сообщения и ветки). Прогресс читателя сохраняется вместе с версией. Если историю обновили (изменился текст), версия меняется и прогресс этой истории у читателя обнуляется. Изменения описания, предисловия, обложки или фона прогресс не сбрасывают.
